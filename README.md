# World Clock

An interactive, responsive world clock for checking the time across time zones at a glance. It displays Los Angeles, Rome, Bangkok, and Fiji, with options to inspect another city or your current location.

## Features

- Live date and time for multiple time zones, refreshed every second
- City selector with current-location detection
- 12-hour and 24-hour formats, with the preference saved in the browser
- Responsive layout and keyboard-visible focus states

## Built With

- HTML5 and CSS3 for semantic structure, responsive presentation, and accessible controls
- Vanilla JavaScript for clock rendering, city selection, and persistent preferences
- Moment.js and Moment Timezone for time-zone-aware date and time formatting
- Bootstrap CSS for layout utilities

The libraries are loaded from CDNs; this project has no build step or package installation requirement.

## Run Locally

Open `index.html` in a web browser.
